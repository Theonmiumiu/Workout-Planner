# 动作肌群与参与系数审查

审查日期：2026-10-27。范围为 40 个内置动作及原有 78 个器械版本；当前共 81 个版本，另外按 43 个肌群区域记录器械参与参数。未读取用户浏览器中的自定义动作。

## 结论

大部分动作的主肌群方向合理，但原先的参与百分比不能认定为大体准确：它只是手工系数除以系数总和，不是测量值，也不是有置信区间的预测。即使有肌电数据，也不能把不同肌肉的肌电值归一化后解释为发力、机械张力或增肌贡献的份额。[Vigotsky 等，2018](https://pubmed.ncbi.nlm.nih.gov/29354060/)

本次核对的是动作任务与肌群归属；并未验证每个动作在每个人、每个器械上的具体刺激剂量。动作库现展示器械版本、细分区域参与和具体处方，不展示发力百分比。

## 已修正的问题

1. **稳定参与被误当增肌组数。** 将下拉／划船／RDL 的握持、俯卧撑等的躯干固定、推肩及臂屈伸的稳定参与单独列出，默认不折算成相应部位的增肌工作组。这是保守记账选择，不表示这些肌肉没有活动、不会疲劳或不能产生适应。核心抗伸展本身就是平板支撑的主要任务，所以直接核心训练仍可记账。
2. **深蹲、腿举和臀推被当作腿后侧补量。** 深蹲研究没有显示与股四头和臀部同等的腘绳肌增长；不能因腘绳肌参与协调就认为足够替代屈膝或髋铰链训练。程序不再通过这些动作的少量参与凑腘绳肌预算。腿举的处理是基于类似任务和保守推断，不是声称已测得其腘绳肌贡献为零。[Kubo 等，2019](https://pubmed.ncbi.nlm.nih.gov/31230110/)、[Plotkin 等，2023，正式发表版本](https://pubmed.ncbi.nlm.nih.gov/37877099/)
3. **复合动作的共同主要目标未计入直接组数。** 原实现只认可 primary 中最大系数对应的肌群。现在深蹲与 RDL 的臀部也进入主要目标组数与频次；仍保留主导任务决定分化归属的规则。直接组数是动作目标的组数统计，不是测得的同等有效组。
4. **上背标签不完整。** 名称补充菱形肌，说明划船还涉及斜方肌不同区域，肘轨迹和肩胛动作会改变偏向。反向飞鸟的后束为主要目标，上背作为辅助。
5. **器械版本被当成生理等效。** 保留相同任务的版本结构，但增加角度、握法和阻力线的限制说明。伸膝式与坐姿屈膝提踵现在需要不同器械，避免只有坐姿设备却被当成站姿；坐姿提踵与伸膝提踵对子肌群的效果不能视为相同。[Kinoshita 等，2023](https://pubmed.ncbi.nlm.nih.gov/38156065/)

## 系数的准确性边界

内置动作的 1／0.75／0.5／0.25 只表达粗粒度工作组记账假设，主要目的是减少虚假的数值精度；从 0.68 改为 0.75 并不意味着新数值被实验验证。它们不是 %MVC、实际肌电占比、力矩贡献或增肌贡献，不能相加归一化后解释为 100% 的人体发力分配。

主要目标与动态辅助采用这些独立系数；稳定／少量参与显示但不自动计入周组数。每个动作工作组对同一统计组别最多计 1 组。各组别可以同时有参与，所以跨肌群没有“总和必须为 1”的约束。

区域方向同样存在不确定性。上斜卧推的锁骨部偏向有研究支持，但不能用该研究直接验证高到低／低到高飞鸟的具体区域系数；后者保留为动作路径的训练偏向和工程标签，证据较弱，不能称为隔离上胸或下胸。[卧推角度研究](https://pubmed.ncbi.nlm.nih.gov/33049982/)

## 当前模型仍有的简化

- 上／中／下胸是胸大肌区域标签，不是三个可以互相独立训练的完整肌群。
- 背部合并了背阔及肩胛相关肌群；总量充足不表示每个背部区域都已得到充分训练。
- 臀部合并了臀大、中、小肌等。髋外展与臀推都参与臀部，但不能互相替代；程序的臀部总预算不证明臀大肌髋伸训练已经充分。器械髋外展的臀中肌目标有研究依据。[髋外展研究](https://pubmed.ncbi.nlm.nih.gov/35500965/)
- 小腿合并腓肠肌和比目鱼肌；腹部合并屈曲和抗伸展任务；前臂合并不同功能。相同“组数”不能证明子肌群和任务等效。
- 肩袖、前锯肌、竖脊肌、肱肌、内收肌等尚未逐一建周预算；重要参与已尽可能写入说明，不能把未列入数字的肌肉理解为不参与。
- 已有自定义动作继续采用用户声明的肌群与系数，没有自动通过本次内置库校核。新增自定义表单已区分动态辅助和稳定参与。

## 兼容性与验证

肌群记账版本为 3，计划算法版本为 5。旧计划处方、原动作版本 id 和历史记录不被自动删改；当前界面按最新动作库重新估算，旧规则计划有提示，重新生成会保存新版本。旧日志的动作快照保留；训练量建议只采用相同记账版本的已核对记录，避免模型改变被误认为用户水平改变。

验证包括全部内置动作的角色完整性、无重叠、粗粒度系数范围、稳定参与不计组、多个主要目标的直接组数、提踵器械条件、旧规则记录隔离，以及原有分化／时长／版本管理流程。测试验证软件符合这些约定，不能验证实际增肌效果。
